# План локального веб-интерфейса

- [x] Обернуть обработку одного изображения в отдельный конвейер с событиями геометрии, OCR, ячеек и матчинга.
- [x] Добавить локальный HTTP-сервер: `0.0.0.0`, порт `8023` по умолчанию, `--host` / `--port` для изменения.
- [x] Сделать двухпанельный интерфейс: входные изображения слева, прогресс и электронный чек справа.
- [x] Поддержать кнопку загрузки, drag-and-drop и вставку изображения из буфера.
- [x] Показывать операции над изображениями, рамки OCR и ячеек, ход обработки и причины проверки товара.
- [x] Проверить API, реальную обработку двух фото с НДС, интерфейс в браузере; добавить инструкцию запуска.
- [x] Собирать чек во время OCR, заменять названия при матчинге, оставить сырой OCR неизменным.
- [x] Добавить форму проверки над чеком: выбор справочника, подтверждение названия, правки количества/цены и журнал изменений.
- [x] Проверять денежную сумму точно через Decimal, отдельно учитывать НДС/доставку, показывать расхождения и управлять финальным утверждением.
- [x] Поставить шапку после оригинала, применять включительный порог окраски, увеличить шрифт таблицы втрое, окрашивать совпавший итог зелёным, заменить жёлтую рамку НДС нейтральной.

Решения: Python из `.venv`; существующие функции геометрии, OCR и матчинга используются повторно. Без облачного размещения и передачи фото. Артефакты веб-загрузок — в `web_outputs/<job_id>/`, пакетные `eval_outputs` не перезаписываются. События передаются через Server-Sent Events; прогресс отражает реальные этапы, визуальная анимация рамок выполняется браузером.

Проверено: 81 тест pytest; браузер Microsoft Edge — загрузка кнопкой, drag-and-drop, вставка изображения, живые рамки, реальный поток черновиков до матчинга, порядок шапки, корректная группировка НДС на двух реальных фото, увеличение, фильтр проверки, поиск товара и редактирование, обнаружение расхождения суммы, исправление пропущенного количества, включительный порог окраски, утверждение и восстановление после перезагрузки, неизменность исходного OCR, мобильная ширина. Контрольные суммы: 36 656,00 ₸ и 642 756,00 ₸ после ввода отсутствующего количества 1. Скриншоты и протоколы: `web_outputs/browser_check/`. Инструкция: [web_ui.md](web_ui.md).
