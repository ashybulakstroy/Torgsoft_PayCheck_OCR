# Выпрямление по контурам — 26.10.2026

По запросу пользователя созданы выпрямленные варианты всех 22 таблиц из сохранённых полигонов `debug_notes/contour_fix/results.json`.

В каталоге каждого исходного фото внутри `eval_outputs/<имя фото>/`:

- `rectified.png` — выпрямленная таблица с полями, без диагностической обводки;
- `warped.png` — идентичная копия для совместимости с прежним просмотрщиком;
- `rectification.json` — параметры, исходный полигон, статус и предупреждения;
- `rectification_map.npz` — отображение каждого пикселя результата в координаты исходной фотографии, массивы `map_x` / `map_y`.

Просмотр: [галерея](../eval_outputs/rectified_review.html), [монтаж](../eval_outputs/rectified_contact.jpg), [сводные метаданные](../eval_outputs/rectification_summary.json).

Метод реализован в `App/contour_unwarp.py`: нелинейная поверхность Coons по верхнему контуру, боковым границам и основной нижней линии. Нижняя ячейка итога располагается в дополнительной полосе; её ступенька не растягивается на всю таблицу. Пиксели берутся из исходного JPEG одним `cv2.remap` с кубической интерполяцией. Рамка и исходные фотографии не перерисовываются.

Для трёх ранее спорных контуров верхний край аппроксимируется прямой, чтобы внутренние ответвления не создавали произвольного изгиба. Их предупреждения сохранены: `2026-10-22 at 16.15.19`, `2026-10-23 at 13.57.55`, `2026-10-25 at 13.16.05`.

Это варианты для визуальной проверки (`review_preview`), созданные отдельно от консервативного автоматического выбора перед OCR. Внутренние линии таблицы не использованы как полная сетка деформации; возможна остаточная кривизна. Улучшение OCR не измерялось. Шапка, штрихкод и прочие области вне таблицы доступны на неизменённом оригинале, а не в этом табличном кропе.

Проверено наличие и читаемость 22 изображений и карт, совпадение размеров, конечность координат и положительный Jacobian без складок. Просмотрены монтаж всех результатов и отдельные сложные изображения. Добавлены тесты выпрямления изогнутой верхней линии, сохранения полосы итога и устойчивости к отсутствующему углу и внутренним вершинам нижней рамки.

Повторить генерацию:

```powershell
python -m App.contour_unwarp
```

Пакетный оценщик сохраняет явно созданные варианты: при наличии `rectification.json` он не удаляет и не перезаписывает `warped.png`.
