# Рабочее разделение объединённых числовых ячеек

`App/numeric_cell_split.py` включён в `ReceiptPipeline.process` после чтения
количеств из отдельных ячеек, до публикации окончательных строк OCR и матчинга.
Зависимостей от `experiments`, `debug_notes` и эталонов тестов в рабочем модуле нет.

При отсутствующем/нечисловом количестве или цене проверяется единственный
исходный OCR-блок той же строки, пересекающий границу столбцов количества и цены.
Требуются явный разделитель и два однозначных положительных числа. Корректные
имеющиеся значения не заменяются. Предложенные значения применяются только
после полной проверки печатной суммы и НДС.

Названия, границы и номера строк, raw-числа, исходные OCR-блоки сохраняются.
Меняются только рабочие `quantity` и `price`; источник сохраняется в
`numeric_split_evidence`. Инициализация строк перед матчингом сохраняет обе
исправленные величины.

В каталоге каждого нового веб-задания создаётся `numeric_split.json` с
диагностикой. При применении исправления событие обработки сообщает количество
разделённых пар; журнал доступен в режиме разработчика. Диагностический JSON
можно получить через обычный файловый API задания.

Неоднозначный блок, обычный пробел между цифрами, изменение корректного числа,
ошибка суммы/НДС или отсутствие проверяемого итога приводят к сохранению прежних
значений. Пересегментация строк и перенос названий сюда не входят.

Проверки внедрения: 151 автоматический тест; 61 сохранённый веб-чек — 2 улучшения,
0 ухудшений, 59 без изменений. Два улучшения относятся к повторным загрузкам
одного подтверждённого фото. Набор 26 фото — без изменений. Новый реальный
браузерный проход после перезапуска сервера подтвердил количество, цену,
математику и восстановление результата после перезагрузки страницы.

В истории на момент проверки было меньше 100 чеков; пользователь явно разрешил
включить этот ограниченный алгоритм в рабочее приложение.

```powershell
& .\.venv\Scripts\python.exe -m experiments.local_numeric_split
& .\.venv\Scripts\python.exe -m pytest App/tests -q
```
