# Локальное разделение количества и цены

Подтверждённая логика перенесена в рабочий модуль `App/numeric_cell_split.py`
и включена в `App/web_pipeline.py`. Файл `experiments/local_numeric_split.py`
остался адаптером проверки и вызывает этот же рабочий модуль.

Вместо перестройки всей сетки проверяются только строки с отсутствующим или
нечисловым количеством/ценой. Нужен ровно один исходный OCR-блок этой строки,
пересекающий разделитель количества и цены и содержащий явный разделитель
`|`, `!`, `I` или `l` между двумя положительными числами. Пробел не считается
границей ячеек. Корректные имеющиеся числа не переписываются.

Числа извлекаются из OCR, не вычисляются из суммы. Результат принимается
только при успешной полной проверке печатного итога и НДС. Иначе возвращается
прежний чек. Названия, raw-поля, исходные блоки, типы/номера строк и их границы
сохраняются; исправляются только рабочие `quantity` и `price`, с отдельным
свидетельством `numeric_split_evidence`.
